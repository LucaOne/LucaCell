This repository contains the code and resources for LucaCell, including pretraining code, downstream task code, embeddings, and raw data.     

Directory structure       

LucaCell/           
Pretraining code for LucaCell.         

LucaCellTasks/         
Code for downstream tasks and evaluation.         

data/         
Directory for raw data used in downstream tasks. The data should be downloaded from Zenodo:          
https://zenodo.org/records/22073984      

embedding/          
Directory for precomputed sequence embeddings from LucaOne and cell embeddings from LucaCell.         
The embeddings should be downloaded from Zenodo:           
https://zenodo.org/records/22073984           

Notes        
The data/ and embedding/ directories are empty in the repository and need to be populated using the files downloaded from Zenodo.
